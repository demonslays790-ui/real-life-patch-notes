One deadpan patch note about a small real-life change — 118 characters, dry changelog register with the funny turn saved for the last few words:

> Patch 1.4: The washing machine now finishes when it says it will. Known issue: the extra 12 minutes were load-bearing.

`main.py` (standard library only) writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, with no trailing newline and a 1–160 character, single-line guard that exits non-zero if the line ever violates the gate.

## Run it

```sh
python3 main.py
```

That writes `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to write somewhere else).
